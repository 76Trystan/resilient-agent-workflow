# Cuppa-Tea-Temporal
Based off the Cuppa Tea Example but incorporating Temporal's durable runtime features.

---

## Setup

#### 1. Temporal Server
   
```
temporal server start-dev
```

### 2. Temporal Worker 

```
cd src
npm run worker
```

#### 3. Run Server  

```
npm run server
```

#### 4. Frontend UI

```
npm run dev
```
